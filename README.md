# dart-ai

AI-based dart score detection system using computer vision and real-time streaming.

## Stack
- **Backend:** Python 3.13, FastAPI, SQLAlchemy, Alembic
- **Vision:** OpenCV, YOLOv11n (ultralytics), NumPy
- **ML:** PyTorch (MPS on Apple Silicon)
- **Database:** PostgreSQL 16
- **Frontend:** React 18, Vite, Tailwind CSS

## Setup
```bash
git clone https://github.com/OliverChopart/dart-ai.git
cd dart-ai
python scripts/setup.py
```
